# Juniper & Co. Café Website

A modern, responsive café website made with HTML, CSS and vanilla JavaScript.

## Included sections
- Welcome / hero section
- Café introduction / story
- Food and drinks menu with category filters
- Seasonal special item
- Customer review cards
- Opening hours and contact information
- Location panel with Google Maps directions link
- Responsive navigation for mobile screens

## Run the website
1. Extract `cafe-website.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to view it in a browser.

No installation or build tools are required.

## Customize
- Edit menu items and prices in `script.js`.
- Update the café name, reviews, address, hours and contact information in `index.html`.
- Replace the sample image URLs in `style.css` with your own café photography.

## Demo content notice
Juniper & Co. and its address, contact information, menu prices and customer reviews are fictional sample content. The location link is a general Google Maps search for Jubilee Hills, Hyderabad, not a verified business listing.
